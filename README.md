# SAIRAN — Strategic AI Readiness Assessment Navigator

MVP platform that evaluates organizational readiness for AI adoption across five dimensions: **People, Process, Technology, Ecosystem, Governance.**

Users complete a 25-question questionnaire; the system produces weighted dimension scores, an overall readiness level (Basic / Developing / Advanced), prioritized recommendations, and an attestation-ready report.

---

## Stack

| Layer | Tech |
|---|---|
| Frontend | Next.js 14 (App Router) · TypeScript · Tailwind CSS · Radix UI · Recharts · next-auth v5 |
| Backend | Python 3.11+ · FastAPI · SQLAlchemy · Pydantic · JWT (python-jose) |
| Database | SQLite (dev) → PostgreSQL (prod on AWS RDS) |
| Hosting target | AWS (ECS Fargate or App Runner + RDS + S3/CloudFront) |

UI template: **DashCode Next.js 2.0** — admin dashboard template, with SAIRAN pages added under `app/[locale]/(protected)/sairan/*`. Demo pages from the template are still present but hidden from the sidebar; you can delete them when no longer useful.

## Prerequisites

1. **Node.js 18+** — verify with `node -v`.
2. **Python 3.11 or 3.12** — *install this first if it's missing.*

## Setup

### 1. Backend

```bash
cd backend
python -m venv .venv

# Windows (cmd)
.venv\Scripts\activate
# Windows (git bash)
source .venv/Scripts/activate

pip install -r requirements.txt
cp .env.example .env                 # defaults are fine for local dev
python -m app.seed                   # creates sairan.db, seeds questions + demo orgs
uvicorn app.main:app --reload        # http://localhost:8000
```

API docs at http://localhost:8000/docs (Swagger UI auto-generated by FastAPI).

### 2. Frontend

```bash
cd frontend
npm install                           # first time only
npm run dev                           # http://localhost:3000
```

The frontend reads `NEXT_PUBLIC_API_URL` from `frontend/.env` (already configured to point at `http://localhost:8000/api/v1`).

## Demo walkthrough (golden path)

1. Open http://localhost:3000 and log in as `orgadmin@sampleb.com / demo123`.
2. Dashboard shows the completed **AI Readiness Baseline 2026** at Developing level (~3.18).
3. Click **Start New Assessment** → name it → you're taken to the questionnaire.
4. Answer all 25 questions (auto-saves at each change; switch dimensions via the step pills).
5. On the last question, click **Submit assessment**.
6. You land on the **Results** page with radar chart + dimension breakdown.
7. **View recommendations** → **Generate report** → use browser print to save PDF.
8. Log out, log back in as `admin@sairan.ph / admin123` to see the Admin sidebar (Question Bank, Organizations, Scoring Configuration).

## Scoring model (reference)

Implemented in `backend/app/services/scoring.py`:

- Each answer maps to a numeric value via the question's `answer_options` (e.g. Yes=5, In Progress=3, No=1).
- **Weighted question score** = answer value × question weight (weight 1–3).
- **Dimension score** = Σ(weighted question scores) ÷ Σ(weights), rounded to 2 decimals.
- **Overall score** = arithmetic mean of the 5 dimension scores (equal weighting).
- **Readiness level thresholds:**
  - Basic: 1.00 – 2.49
  - Developing: 2.50 – 3.49
  - Advanced: 3.50 – 5.00

Questions and weights are configurable via the System Admin's Question Bank (list view is shipped; edit-in-UI is a follow-up — the API endpoints are already live).

## Troubleshooting

- **`python` not found on Windows**: Microsoft Store alias got in the way. After installing Python from python.org, close and reopen your terminal, or run `where python` to confirm it's resolving to `C:\Python3XX\python.exe`.
- **Login returns 401**: make sure the backend is running on port 8000 and `python -m app.seed` completed successfully.
- **CORS error in browser**: `backend/.env` defaults to allowing `http://localhost:3000`. If you run the frontend on a different port, add it to `CORS_ORIGINS`.
- **`pip install` fails on bcrypt/cryptography**: make sure you're on Python 3.11 or 3.12. Python 3.13 requires newer wheels that may not be available yet.
